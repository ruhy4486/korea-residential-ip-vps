## 双 ISP 住宅 IP 到底怎么验，别只看商品名

“住宅”两个字写在标题上，不等于 IP 真的属于住宅段。目前市面上最常见的做法是把机房广播段包装成家宽出售，检测工具单一维度看着像，实际用起来平台照样风控。

判断真住宅，看两个维度是否同时满足：

1. **Company 类型显示为 ISP**，说明 IP 归属方是网络服务提供商，不是数据中心。
2. **ASN 类型同样显示为 ISP**，两个维度互相印证，才是完整的双 ISP 住宅 IP。

只满足其中一个的，大概率是伪装段。除此之外还有三步可以叠加验证：

- 用两个以上不同的 IP 检测工具交叉比对，单一工具的结果可能被针对性优化过。
- 查 IP 的注册信息和路由轨迹，真住宅 IP 的归属链路能对应到当地运营商的宽带网络。
- 拿到手直接跑自己的业务环境，风控严格的平台一用就知道真假。

WePC 这款 SEJONG 产品在多数检测平台上被识别为住宅网络，属于通过双 ISP 检测的类型。到手后仍建议自己复验一遍，不同批次 IP 的纯净度会有差异。

## 常见问题

**住宅 IP 和普通 VPS 的区别在哪？**
普通 VPS 分配的是数据中心机房段 IP，平台查 ASN 就知道是服务器环境。住宅 IP 的 ASN 归属是本地宽带运营商，风控视角下更接近普通家庭用户。做电商店铺、社媒账号这类对登录环境敏感的业务，差别很明显。

**双 ISP 是什么意思？**
IP 的 Company 类型和 ASN 类型都显示为 ISP，两个维度互相印证。单一维度满足的 IP 可能是广播段伪装。

**512MB 内存能装什么？**
轻量 Linux 服务、代理程序、单账号环境够用。带面板的多进程环境、数据库、Windows 系统都不合适。

**联通用户能用吗？**
能连，但线路绕路，延迟会高于电信和移动。对延迟敏感的场景建议配中转。

**TikTok 为什么会识别成新加坡？**
这是第三方测评的实际测试结果，具体原因没有官方说明。如果你的业务要求账号明确归属韩国，购买前务必自己小规模验证。
